# 🧠 Daily LeetCode Practice – u2tdam

Chào mừng bạn đến với **Daily-LeetCode-u2tdam** – nơi mình lưu trữ quá trình rèn luyện thuật toán hàng ngày thông qua các bài tập LeetCode. Đây là một dự án cá nhân nhằm nâng cao tư duy lập trình, khả năng giải quyết vấn đề và chuẩn bị cho các kỳ phỏng vấn kỹ sư phần mềm.

## 📌 Mục tiêu dự án

- Giải ít nhất 1 bài LeetCode mỗi ngày.
- Rèn luyện các chủ đề quan trọng: Array, String, Linked List, Binary Tree, Graph, Dynamic Programming,...
- Ghi chú lại cách tiếp cận, thuật toán và tối ưu hoá.
- Hệ thống lại lộ trình học giải thuật theo mức độ khó.
